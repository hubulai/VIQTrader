P2 引擎层：三阶段交易规则管线 + 双轨账本 + 执行网关

## 新增

### 0003 迁移（只增不改）
- 新表：order_intent（订单意图全生命周期）、market_status（涨跌停/停牌/ST/港股通名单快照）、rule_check_log（规则校验流水）
- 加列：dim_stock.board、position.frozen_qty（NULL 容忍 + 回填 0，DuckDB 限制）、trade_log.intent_id
- FK 引用关系由应用层保证（DuckDB ADD COLUMN 不支持外键）

### engine 包（第 5 层，契约保持 web > orchestrator > agents > domain > engine > data > store > base）
- types.py：OrderIntent（frozen 不可变）、RuleContext、MarketStatusView、PositionView、FeeBreakdown、TradeLog、InsufficientCashAtFill；金额全程 Decimal，to_decimal overload 区分有无默认值
- market_status.py：涨跌停价预计算（板块/ST 差异化涨跌幅、四舍五入到分）、停牌判定（无 bar 或零量）、dim_stock.board 回填、幂等重跑
- fees.py：A 股（佣金双边最低 5 元、印花税卖出单边、过户费双边）+ 港股通（双边印花税/交易费，原币计算折 CNY），统一 CNY 口径
- rules/：TradingRule Protocol + TradingRuleEngine 三阶段管线（MARKET → ACCOUNT → RISK，硬拒绝即终止，WARN 不阻断）
  - Phase1 市场：T1Rule、TradingDayRule、SuspensionRule、PriceLimitRule、LotSizeRule（科创板 200 股起 1 股递增、港股通 v1 简化）、HKConnectRule（调出名单只能卖）
  - Phase2 账户：CashSufficiencyRule（含费用预估）、PositionLimitRule（冻结量剔除）、ModeIsolationRule（双轨隔离红线）、QuotaRule（80/20 软限制——超限 WARN + risk_event(ALERT) 不阻断，已确认决策）
- ledger/engine.py：LedgerEngine——FILLED 才扣款且扣款前重检资金（失败抛 InsufficientCashAtFill 全事务回滚）；A 股 T+1 买入冻结/日终解冻；加权成本；SELL 返回 realized_pnl（人民币口径成本）；港股通分红统一 0.20 税率按汇率折 CNY；同标的双轨各入各账
- execution/：SimulatedGateway（回测按当日 bar：MARKET 开盘价 ± 10bp 滑点、涨跌停封死不成交、LIMIT 触及成交）、DryRunGateway（模拟盘参考价 dry-run）、build_rule_context（现金/市值/汇率/当前价汇总）、ExecutionService（intent 落库 → 三阶段校验 → rule_check_log → risk_event → 网关撮合 → 账本记账 → 状态回写，全链留痕）
