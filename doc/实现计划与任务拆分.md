# 股票分析交易平台 · 实现计划与任务拆分

> 依据《股票分析交易平台设计方案》v1 范围拆分；P2 实现依据《A股交易规则引擎与双轨账本详细设计》v1.1（2026-10-15 已确认：双轨配额软限制、Intent 不冻结资金）。
> 原则：每个阶段产出**可运行、可验证**的成果；验证方式在任务卡里写死；遵守设计文档第十二节的变更安全纪律（契约先行、盒带先行、黄金数据集先行）。
> 状态：**已于 2026-10-15 开工执行**；实际进度见工程根目录 `README.md`，任务卡如需调整按文末「变更记录」追加条目。
> 路径约定：产出物按实际 src 布局书写；仅写包名时（如 `agents/value/`、`learning/`）指 `src/viqtrader/<包名>/`。

## 里程碑总览

| 里程碑 | 包含阶段 | 完成标志 |
|---|---|---|
| **M1 数据可信** | P0 工程地基 + P1 数据层 | 本地库每日可同步，数据抽查与 QMT 终端一致 |
| **M2 钱算得清** | P2 账本 + 撮合 + 风控 | 构造场景全通过：T+1/涨跌停/配额/能力圈/港股通限售 |
| **M3 策略可验证** | P3 回测 + Walk-Forward + 生命周期 | 黄金数据集回测结果可手工核对；过拟合策略被门禁拦下 |
| **M4 研究能产出** | P4 Agent 层 | 真实跑通一次投委会（茅台），输出人工评审合格 |
| **M5 平台转起来** | P5 编排与学习地基 + P6 控制台 | 端到端 dry-run 一周；控制台完成一笔人工确认模拟交易 |

依赖关系：P0→P1→P2→P3→P5→P6 为主线；**P4（Agent 层）不依赖 P3，可在 P2 后与 P3 并行**。

**当前进度（2026-10-15）**：P0 全部完成；P1 进行中——1.1 建表、1.2 契约套件、**1.4 AkShare 适配器已完成**，1.3 待 QMT 终端可用时实测，1.5~1.8 待办；P2~P7 未启动。

## 执行纪律（贯穿所有阶段）

1. 每个任务完成 = 代码 + 测试 + 验证方式全过，缺一不可。
2. 引擎层（账本/撮合/风控/回测/Brinson/Walk-Forward）**纯函数优先，零 LLM**。
3. 每阶段结束跑一次黄金数据集回归（M2 起可用回放工具）。
4. config 阈值默认值全是占位——**以你在 P2 前提供的真实值为准**，之后改动走快照机制。
5. 数据源冒烟测试（QMT/AkShare 连通性）纳入每日任务，失效走 FATAL 告警。
